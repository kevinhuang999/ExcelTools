ExcelTools 使用说明
==================

一、这是什么
-----------
Excel 里的 11 个数据处理工具，装在「Excel 工具」选项卡下。
把平时手工搬几小时的活压成一键：拆分工作表、条件筛选、按列排序、
删除匹配行、两表比对、差异比对、累计去重计数、分组统计、权限矩阵、
多字段匹配、文件名列表。


二、怎么开始用
-------------
安装程序装完之后，打开 Excel 就会看到「Excel 工具」选项卡。

不需要双击任何文件，不需要每次确认，也不会再弹安全提示。

如果选项卡没出现：
  1. 完全退出 Excel（任务管理器里确认没有 EXCEL.EXE 在跑）
  2. 重新打开 Excel

本插件需要 .NET 10 桌面运行时（.NET 10 Desktop Runtime）。
  - 用的是「完整版（Full）」安装包：安装时如果发现没有，会自动装好，
    过程中会弹一次管理员权限确认，点「是」即可。
  - 用的是「精简版（Lite）」安装包：需要先自行安装，下载地址
    https://dotnet.microsoft.com/download/dotnet/8.0
    64 位 Office 装 x64 版，32 位 Office 装 x86 版。


三、出现「加载项被禁用」怎么办
-----------------------------
如果功能区一直不出现，多半是被 Excel 禁用了（通常发生在缺 .NET 运行时的时候）：

  Excel → 文件 → 选项 → 加载项
  → 最下面「管理」选「禁用的项目」→ 转到
  → 找到 ExcelTools 相关条目，选中，点「启用」

然后重启 Excel。装好 .NET 运行时之后不会再犯。


四、卸载
-------
控制面板 → 程序和功能 → ExcelTools → 卸载（或在 Windows 设置里卸载）。

卸载会把安装目录、Excel 里的加载项注册、以及信任位置记录一并清干净，
不会留下残留。已装好的 .NET 运行时不会被卸载（它可能被别的软件用着）。


五、安装位置
-----------
  %LOCALAPPDATA%\Programs\ExcelTools
  通常就是 C:\Users\<你的用户名>\AppData\Local\Programs\ExcelTools

装在当前用户目录下，不需要管理员权限，也不影响这台电脑上的其他用户。
